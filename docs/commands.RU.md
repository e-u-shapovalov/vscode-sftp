# Справочник команд WireFerry

[English version](commands.md) · [Основной README](../README.RU.md) · [Конфигурация](configuration.RU.md) · [FAQ](../FAQ.RU.md)

Откройте палитру команд через `Ctrl+Shift+P` и введите `WireFerry`. Многие команды передачи также доступны в контекстных меню локального Explorer, редактора, Source Control и Remote Explorer.

Команды, которым нужен сервер, становятся доступны после загрузки корректного `.vscode/wireferry.json` или legacy-файла `.vscode/sftp.json`.

## Настройка и подключение

| Команда | Назначение |
| --- | --- |
| `WireFerry: Config` | Запустить мастер, если конфига нет, или открыть текущий конфиг |
| `WireFerry: Set Profile` | Выбрать активный профиль для команд без явного контекста профиля |
| `WireFerry: Open SSH in Terminal` | Открыть SSH-терминал для текущего SFTP-подключения |
| `WireFerry: Check for Updates` | Проверить последний GitHub Release и предложить обновление |
| `WireFerry: Open Extension Page` | Открыть страницу расширения в VS Code |
| `WireFerry: Cancel All Transfers` | Остановить текущие выгрузки и скачивания |

`Open SSH in Terminal` работает только для конфигураций SFTP/SSH.

## Выгрузка

| Команда | Назначение |
| --- | --- |
| `Upload File` | Выгрузить выбранный локальный или сопоставленный файл |
| `Upload Active File` | Выгрузить открытый в редакторе файл |
| `Upload Folder` | Выгрузить выбранную папку |
| `Upload Active Folder` | Выгрузить папку активного файла |
| `Upload Project` | Выгрузить всё внутри настроенного `context` |
| `Force Upload` | Выгрузить без учёта ignore; альтернативное действие контекстного меню |
| `Upload Changed Files` | Применить на сервере добавления, изменения и переименования из Git working tree/index; перед удалениями задаётся вопрос |

Сочетание по умолчанию для **Upload Changed Files** — `Ctrl+Alt+U`.

Если настроены `profiles`, у команд выгрузки файла, активного файла, папки, активной папки, проекта и force-upload есть варианты **To All Profiles / Во все профили**.

## Скачивание

| Команда | Назначение |
| --- | --- |
| `Download File` | Скачать выбранную удалённую версию с заменой сопоставленного локального файла |
| `Download Active File` | Скачать удалённую версию активного локального файла |
| `Download Folder` | Скачать выбранную папку |
| `Download Active Folder` | Скачать папку активного файла |
| `Download Project` | Скачать настроенный удалённый проект |
| `Force Download` | Скачать без учёта ignore; альтернативное действие контекстного меню |

Передача может перезаписать существующие файлы. Сначала проверьте `context`, `remotePath`, выбранный профиль и исключения.

## Синхронизация и сравнение

| Команда | Назначение |
| --- | --- |
| `Sync Local -> Remote` | Использовать локальное дерево как источник, а сервер как приёмник |
| `Sync Remote -> Local` | Использовать сервер как источник, а локальное дерево как приёмник |
| `Sync Both Directions` | Сравнить время изменения и поместить более новую версию на обе стороны |
| `Diff with Remote` | Сравнить выбранный локальный файл с удалённой копией |
| `Diff Active File with Remote` | Сравнить активный файл редактора с удалённой копией |
| `List` | Показать удалённую папку и выбрать файл |
| `List Active Folder` | Показать удалённую папку, соответствующую папке активного файла |
| `List All` | Показать удалённые файлы, доступные ниже `remotePath` |

`syncOption` управляет созданием, обновлением и удалением. Проверьте его перед синхронизацией важных данных. Для **Sync Both Directions** применяются только `skipCreate` и `ignoreExisting`.

## Remote Explorer

| Команда | Назначение |
| --- | --- |
| `Edit in Local` | Скачать удалённый файл и открыть сопоставленную локальную копию для редактирования |
| `View Content` | Открыть удалённый файл только для чтения без сохранения в workspace |
| `Open Remote File by Path` | Ввести абсолютный удалённый путь и открыть файл |
| `Open Symlink Target` | Разрешить удалённый symlink и предложить открыть его цель |
| `Reveal in Explorer` | Показать локальную копию удалённого элемента |
| `Reveal in Remote Explorer` | Показать локальный файл в дереве сервера |
| `Copy Path` | Скопировать удалённый путь |
| `Refresh` | Перезагрузить дерево Remote Explorer |
| `Refresh Active Remote File` | Обновить удалённый элемент активного файла |
| `Show Sizes` / `Hide Sizes` | Включить или выключить размеры в дереве |
| `Sort by Size` / `Sort by Name` | Изменить сортировку дерева |
| `Size & MD5...` | Показать размер на сервере и локально, а при возможности — MD5 файла или папки |
| `Show Tree...` | Построить ASCII-дерево выбранной папки в текстовой вкладке, с необязательными размерами файлов и ограничением глубины |

При `wireferry.downloadWhenOpenInRemoteExplorer: true` клик по удалённому файлу скачивает его с progress и затем открывает. При `false` WireFerry открывает read-only preview.

Размер папки считается серверной командой `du`, если она доступна по SFTP; иначе WireFerry обходит удалённое дерево. Серверный MD5 требует подходящих shell-команд и недоступен на FTP.

`Show Tree...` сначала спрашивает, как рисовать дерево (только папки, с файлами или с файлами и размерами) и максимальную глубину (пусто или `0` — без ограничения). Дерево открывается в текстовой вкладке и обрывается на 20000 записях для очень больших папок. Команда доступна на папках и в Remote Explorer, и в локальном Explorer.

## Управление удалёнными файлами

| Команда | Назначение |
| --- | --- |
| `Create File` / `Create Folder` | Создать элемент внутри выбранной удалённой папки |
| `Rename` | Переименовать или переместить выбранный удалённый элемент |
| `Delete (server / local / both)...` | Выбрать удаление на сервере, локально или с обеих сторон |
| `Change Permissions (chmod)` | Изменить Unix-права; папку можно обработать рекурсивно |
| `Change Owner / Group (chown, as root)` | Выполнить `chown` через `su` на совместимом SSH-сервере |

При наличии профилей окно удаления также может удалить серверную копию из каждого профиля и переместить единственную локальную копию в Корзину ОС.

При локальном удалении WireFerry запрашивает Корзину ОС. Если она недоступна, например на некоторых сетевых или subst-дисках, реализация переходит к безвозвратному удалению.

Привилегированный повтор `chmod` и `chown` требуют SFTP/SSH, работающую команду `su` и корректные данные root.

## Учётные данные

| Команда | Назначение |
| --- | --- |
| `Generate SSH Key...` | Создать SSH-ключ, развернуть публичную часть и переключиться после проверенного входа |
| `Save Password to Keychain...` | Сохранить пароль через VS Code SecretStorage и обновить конфиг |
| `Delete Saved Password...` | Удалить выбранные пароли или passphrase из SecretStorage |

Создание SSH-ключа доступно только для SFTP. Хранение пароля работает для основных конфигураций и профилей; учётные данные jump host в SecretStorage не сохраняются.

## Интеграция с локальным Explorer

Контекстное меню локального Explorer содержит действия выгрузки, скачивания, синхронизации, diff, удаления, Size & MD5 и Show Tree для сопоставленных элементов.

`Copy Path (Git Bash)` преобразует выбранные Windows-пути вида `C:\project\file` в формат Git Bash `/c/project/file`.

Локальное переименование или перемещение можно после подтверждения применить на сервере. Удаление через VS Code также можно после подтверждения повторить на сервере; внешние изменения файловой системы не вызывают эти два обработчика подтверждения.
